## Regenerating

```bash
# From inside WSL:
source ~/catan_mcts_venvs/mcts-study/bin/activate
cd /mnt/c/dojo/catan_bot/.claude/worktrees/v3/mcts_study

# Six figures from the deep-analysis script (replay-heavy; ~25 min)
python analyses/fullcatan_plots.py

# Two figures from the rules-matrix plot (just data, no replay; ~5s)
python analyses/rules_matrix_plot.py
```

The figures end up at `docs/superpowers/journals/figures/`. The `analyses/` scripts hardcode that output path.
